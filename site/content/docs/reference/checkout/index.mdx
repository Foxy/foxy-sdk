Cart and checkout for the browser. It has a shared `client`, a side cart drawer, and add-to-cart links and forms. Load it from npm, or from the Foxy CDN with no build step.

```sh
npm i @foxy.io/sdk@2
```

```ts
import { client } from '@foxy.io/sdk/checkout';
```

From the CDN, the store domain goes in the `store` parameter:

```js
import { client } from 'https://cdn-js.foxy.io/sdk@2/checkout/loader.js?store=example.foxycart.com';
```

## Example

Add an item to the cart. From npm, set the store first. The CDN loader does this for you through `?store=`.

```ts
client.setStoreDomain('example.foxycart.com');

client.addItem([
  ['name', 'Mug'],
  ['price', '15'],
]);
```

Show the cart drawer. The loader turns it on, and handles add-to-cart links and forms.

```js
import { sideCart } from 'https://cdn-js.foxy.io/sdk@2/checkout/loader.js?store=example.foxycart.com';

sideCart.show();
```

## Learn more

- [`client`](/docs/reference/checkout/variables/client): the shared client.
- [`sideCart`](/docs/reference/checkout/variables/sideCart): the drawer.
- [`loader`](/docs/reference/checkout/loader): sets the store, and turns on the drawer and add-to-cart links and forms.
