```ts
type SessionHost = object;
```

What `CartSession` needs from the `API` that owns it. Only the SDK creates one.

## Methods

### changed()

```ts
changed(sessionId): void;
```

Tells the sidecart: reload with this ID, or unmount for null.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `sessionId` | `string` \| `null` |

#### Returns

`void`

***

### clear()

```ts
clear(): void;
```

Sets the client's json to null.

#### Returns

`void`

***

### load()

```ts
load(sessionId): Promise<void>;
```

`GET /cart` with this ID (or none: a new session), then replaces the client's json.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `sessionId` | `string` \| `null` |

#### Returns

`Promise`\<`void`\>

***
