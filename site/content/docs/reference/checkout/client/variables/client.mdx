```ts
const client: API;
```

The shared checkout API client. Every import of `checkout/client` or `checkout/loader` gets this same instance.

## Example

```ts
import { client } from '@foxy.io/sdk/checkout/client';

client.setStoreDomain('example.foxycart.com');

// Add a product with a quantity and a custom option.
client.addItem([
  ['name', 'Mug'],
  ['price', '15'],
  ['quantity', '2'],
  ['color', 'Blue'],
]);
```
