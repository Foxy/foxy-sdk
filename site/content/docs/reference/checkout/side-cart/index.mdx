A cart drawer over your page. It shows the store's cart in an iframe. The module exports [`sideCart`](#sidecart), whose type is [`SideCart`](#sidecart-type). Importing it also changes how the shared [`client`](/docs/reference/checkout/variables/client) works on your page.

From the CDN, the store domain goes in the `store` parameter. It is not needed when [`loader`](/docs/reference/checkout/loader) already set the store.

```js
import { sideCart } from 'https://cdn-js.foxy.io/sdk@2/checkout/side-cart.js?store=example.foxycart.com';
```

## What importing it does

1. If the client has no store yet, it sets the one from its `store` parameter. The client then loads the shopper's cart and session.
2. The client sends cart changes to the drawer instead of to the store. This applies to `addItem()`, `updateItemQuantity()`, `removeItem()`, `clearCart()`, `applyCouponOrGiftCardCode()`, `removeCouponCode()` and `removeGiftCardCode()`. On your page, these calls do not fire the client's cancelable events, like `item-update` and `cart-clear`. The drawer's own page fires them.
3. [Add-to-cart](/docs/reference/checkout/add-to-cart) links and forms put items in the drawer and open it, instead of going to the cart page.
4. If no store is set by the time the page's `load` event fires, it logs a warning to the console, and `sideCart.itemCountUnavailable` becomes `true`.

The iframe is not created on import. `sideCart.mount()` or the first `sideCart.show()` creates it.

## Example

```ts
import { sideCart } from 'https://cdn-js.foxy.io/sdk@2/checkout/side-cart.js';

// Open the drawer from your own cart button.
document.querySelector('#cart-button')?.addEventListener('click', () => {
  sideCart.show();
});

// Close it when the shopper presses Escape.
document.addEventListener('keydown', event => {
  if (event.key === 'Escape') sideCart.hide();
});

// Keep a cart badge in sync with the side cart.
const badge = document.querySelector('#cart-badge');
const updateBadge = () => {
  if (badge) badge.textContent = String(sideCart.itemCount ?? 0);
};

sideCart.addEventListener('itemcountchange', updateBadge);
updateBadge();
```

## Accessors

### itemCount <MemberMeta type="number | null" getter /> [#itemcount]

`null` means "not known yet", which is not the same as an empty cart.
Most-recent-wins: what the [iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe) reported this session, then the
client's own json, then the persisted cache. A delegated mutation never
refreshes `client.json` -- it forwards to the transport and returns --
so once the iframe has reported, its number is the only one still being
kept live and must outrank the client's page-load snapshot.

This is a count of units, not line items -- the cart page inside the
iframe (and its `ready`/`state` reports) shows a total quantity, e.g. a
cart holding 3 of one product reads "Your cart - 3 items", not 1. The
middle tier has to use the same rule or the badge would read 1 until the
frame connects and then silently jump to 3. `Math.max(0, ...)` clamps a
negative quantity to 0 rather than letting it subtract from the total.

***

### itemCountUnavailable <MemberMeta type="boolean" getter /> [#itemcountunavailable]

`true` when the count could not load (the first cart load failed, or no
store domain was ever set) and no count is known. A count that arrives
later makes it `false` again.

***

### open <MemberMeta type="boolean" getter /> [#open]

`true` while the drawer is open. It becomes `true` when you call [`show()`](#show) and `false` when you call [`hide()`](#hide), before the close animation ends.

## Methods

### hide()

```ts
hide(): void;
```

Closes the drawer. The drawer plays its close animation first, then hides. Fires `close`. Does nothing if the drawer is not open.

#### Returns

`void`

***

### mount()

```ts
mount(): void;
```

Adds the cart [iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe) to the page, hidden, and starts loading the cart in it. Does nothing if it is already mounted. Throws if the store is not known. Set it with the `store` query of the import URL or on the client.

#### Returns

`void`

***

### reload()

```ts
reload(): void;
```

Removes the iframe and adds a new one, so the drawer shows the current cart. If the drawer was open, it opens again.

#### Returns

`void`

***

### show()

```ts
show(): void;
```

Opens the drawer. It mounts the iframe first if needed, and fires `open`. The page behind the drawer becomes inert until the drawer closes. If the cart does not answer in time, the drawer closes again and the client reports an error.

#### Returns

`void`

***

### unmount()

```ts
unmount(): void;
```

Closes the drawer and removes the iframe from the page. Pending cart changes that wait for the iframe fail. Calling `mount()` or `show()` later adds a new iframe.

#### Returns

`void`
