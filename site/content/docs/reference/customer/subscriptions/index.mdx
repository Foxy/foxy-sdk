Subscription rules for the Customer API: which frequencies a customer can switch to, and which next transaction dates they can pick. They read the customer portal settings in the snake_case form the Customer API returns.

```ts
import { getAllowedFrequencies } from '@foxy.io/sdk/customer/subscriptions';
```
