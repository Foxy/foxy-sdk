A convenience wrapper for the payment card embed [iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe). You don't have to use
this class to embed the payment card iframe, but it provides a more convenient
way to interact with the iframe and listen to its events.

This wraps the **`/v1.html` embed**, whose `tokenize()` resolves with a
self-contained encrypted card blob. It is not the v3 vault path: that one
loads the card-entry shell, mints an opaque `tok_` reference, and reports
refusals as `CardEmbedTokenizeErrorCode` contexts — none of which this class
models, since `tokenize()` here rejects without a reason. Reach for
`foxy-payment-card-field` in foxy-elements for the vault flow.

## Example

```ts
import { PaymentCardEmbed } from '@foxy.io/sdk/customer';

const embed = new PaymentCardEmbed({ url: 'https://embed.foxy.io/v1.html?template_set_id=123' });
await embed.mount(document.body);

// Tokenize when the customer presses Enter in the card form.
embed.onsubmit = async () => {
  const token = await embed.tokenize();
  console.log('Token:', token);
  embed.clear();
};
```

## Properties

### onsubmit <MemberMeta type="(() => void) | null" /> [#onsubmit]

An event handler that is triggered when Enter is pressed in the card form.
This feature is not available for template sets configured with the `stripe_connect`
hosted payment gateway due to the limitations of Stripe.js.

## Methods

### clear()

```ts
clear(): void;
```

Clears the card data from the embed.
No-op if the embed is not mounted.

#### Returns

`void`

### configure()

```ts
configure(config): void;
```

Updates the configuration of the payment card embed.
You can change style, translations, language and interactivity settings.
To change the URL of the payment card embed, you need to create a new instance.
You are not required to provide the full configuration object, only the properties you want to change.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `config` | [`PaymentCardEmbedConfig`](/docs/reference/customer/types#paymentcardembedconfig) | The new configuration. |

#### Returns

`void`

### mount()

```ts
mount(root): Promise<void>;
```
