```ts
function getNextTransactionDateConstraints(data, rules): boolean | Constraints;
```

Finds which next transaction date modification rules are applicable to
the given subscription and merges them together.

## Example

```ts
import { API, getNextTransactionDateConstraints } from '@foxy.io/sdk/customer';

const api = new API({ base: new URL('https://example.foxycart.com/s/customer/') });
await api.signIn({ email: 'customer@example.com', password: 'password' });
const subscriptions = await api.follow('fx:subscriptions').get().then(response => response.json());
const subscription = subscriptions._embedded['fx:subscriptions'][0];

// Rules come from the customer portal settings of your store.
const rules = [{ jsonata_query: 'true', min: '1w', max: '3m' }];
const constraints = getNextTransactionDateConstraints(subscription, rules);

// true: any date. false: no changes. An object: limits for a date picker.
console.log(constraints);
```

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `data` | [`SubscriptionData`](/docs/reference/customer/types#subscriptiondata) | Subscription to generate constraints for. |
| `rules` | `boolean` \| `object`[] | Next date modification config from the customer portal settings. |

## Returns

`boolean` \| [`Constraints`](/docs/reference/admin/types#constraints)

Returns true if all modifications are allowed, false if next date can't
be changed by the customer, object with constraints in any other case.
