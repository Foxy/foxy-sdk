## Type aliases

### APIEventMap

Events of the customer [`API`](/docs/reference/customer/classes/API) client by name. The only event is `session`. It fires with the new [`StoredSession`](/docs/reference/customer/types#storedsession) after sign-in, after each successful request (which extends the session), and when [`usesTemporaryPassword`](/docs/reference/customer/classes/API#usestemporarypassword) changes. It fires with `null` after sign-out or when the session expires. Used by [`API.addEventListener()`](/docs/reference/customer/classes/API#addeventlistener) and [`API.removeEventListener()`](/docs/reference/customer/classes/API#removeeventlistener).

```ts
type APIEventMap = {
  session: CustomEvent<StoredSession | null>;
};
```

### APIInit

Settings for the customer [`API`](/docs/reference/customer/classes/API) constructor: the base URL of the store's Customer API, and an optional [`fetch`](https://developer.mozilla.org/en-US/docs/Web/API/Window/fetch) function and a log level.

```ts
type APIInit = {
  /**
   * Numeric log level; methods above this level are no-ops.
   * If omitted, the default level will be used.
   */
  level?: number;

  /**
   * Request handler implementing [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API).
   * This function will be called whenever a resource is requested. Defaults to native fetch or a custom implementation of Fetch API for Node.
   */
  fetch?: typeof globalThis.fetch;

  /**
   * Bookmark [URL](https://developer.mozilla.org/en-US/docs/Web/API/URL) for this API.
   * This is where the tree traversal begins. We also use this URL as a base for relative paths.
   */
  base: URL;
};
```

### Resource

A typed API resource as a request returns it: its fields, its `_links`, and the `_embedded` resources the query zooms in on. `TGraph` is a resource type from [`Rels`](/docs/reference/customer/types#rels), like `Rels.Subscription`, and `TQuery` is the query you sent. [`Response`](/docs/reference/customer/classes/Response) parses to it, and the subscription helpers take it, for example in [`AllowedFrequenciesOptions`](/docs/reference/customer/subscriptions/types#allowedfrequenciesoptions).

```ts
type Resource<TGraph extends Graph, TQuery extends Query<TGraph> | undefined = undefined> = Links<TGraph> &
  Props<TGraph, TQuery> &
  Embeds<TGraph, TQuery>;
```

## Interfaces

### Credentials

A customer's email and password, or a temporary password or one-time code during access recovery. Passed to [`API.signIn()`](/docs/reference/customer/classes/API#signin).

```ts
interface Credentials {
  /** Email address associated with an account. */
  email: string;
  /** Current password during regular sign-in, temporary password or a one-time code during access recovery. */
  password: string;
}
```

### CustomerSession

The session the Customer API returns after sign-in: a session token, a JWT, its lifetime in seconds, and whether the customer must change their password. [`StoredSession`](/docs/reference/customer/types#storedsession) adds the time it was created.

```ts
interface CustomerSession {
  force_password_reset?: boolean;
  session_token: string;
  expires_in: number;
  jwt: string;
}
```

### Graph

The root of the Customer API graph: the signed-in customer, with their name and email and links to their addresses, subscriptions, transactions and default payment method. A customer [`API`](/docs/reference/customer/classes/API) client starts here, so [`API.follow()`](/docs/reference/customer/classes/API#follow) takes these link names.

```ts
interface Graph {
  curie: 'fx:customer';

  links: {
    /** This resource. */
    'self': Customer;
    /** Attributes for this customer. */
    'fx:attributes': Attributes;
    /** List of customer's transactions. */
    'fx:transactions': Transactions;
    /** List of customer's subscriptions. */
    'fx:subscriptions': Subscriptions;
    /** List of customer's addresses. */
    'fx:customer_addresses': CustomerAddresses;
    /** Customer's default payment method. */
    'fx:default_payment_method': DefaultPaymentMethod;
    /** Customer's default billing address. */
    'fx:default_billing_address': DefaultBillingAddress;
    /** Customer's default shipping address. */
    'fx:default_shipping_address': DefaultShippingAddress;
    /** Navigate to this URL to open a cart with subscription details. */
    'fx:sub_token_url': SubTokenUrl;
    /** Navigate to this URL to make changes to this subscription. */
    'fx:sub_modification_url': SubModificationUrl;
  };

  props: {
    /** The FoxyCart customer id, useful for Single Sign On integrations. */
    id: number;
    /** The date of the last time this customer authenticated with the FoxyCart checkout. */
    last_login_date: string;
    /** The customer's given name. */
    first_name: string | null;
    /** The customer's surname. */
    last_name: string | null;
    /** The customer's email address. This is used as the login to the FoxyCart checkout for this customer. */
    email: string;
    /** A tax identification number for this customer. */
    tax_id: string;
    /** The date this resource was created. */
    date_created: string | null;
    /** The date this resource was last modified. */
    date_modified: string | null;
  };

  zooms: {
    default_shipping_address?: DefaultShippingAddress;
    default_billing_address?: DefaultBillingAddress;
    default_payment_method?: DefaultPaymentMethod;
    attributes: Attributes;
  };
}
```

### SignUpParams

Input of [`API.signUp()`](/docs/reference/customer/classes/API#signup): the new customer's email, an optional name and password, and the hCaptcha verification.

```ts
interface SignUpParams {
  /** Signup verification (currently only hCaptcha is supported). */
  verification: {
    /** Verification type. Currently only hCaptcha is supported. */
    type: 'hcaptcha';
    /** hCaptcha verification token. */
    token: string;
  };
  /** Customer's first name, optional, up to 50 characters. */
  first_name?: string;
  /** Customer's last name, optional, up to 50 characters. */
  last_name?: string;
  /** Customer's password (up to 50 characters). If not provided, Foxy will generate a random password for this account server-side. */
  password?: string;
  /** Customer's email address (up to 100 characters), required. */
  email: string;
}
```

### StoredSession

A [`CustomerSession`](/docs/reference/customer/types#customersession) plus the time it was created. After sign-in, the customer [`API`](/docs/reference/customer/classes/API) client keeps it in memory and sends it with the `session` event. Pass a saved one to [`API.setSession()`](/docs/reference/customer/classes/API#setsession).

```ts
interface StoredSession extends CustomerSession {
  date_created: string;
}
```
