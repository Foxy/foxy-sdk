Typed client for the Foxy Customer API. Use it in the browser to build a customer portal: sign in, read the customer's data, and apply the store's portal rules.

```sh
npm i @foxy.io/sdk@2
```

```ts
import { API, getAllowedFrequencies } from '@foxy.io/sdk/customer';
```

## Example

`base` is the Customer API URL of your store.

```ts
const api = new API({ base: new URL('https://example.foxycart.com/s/customer/') });
await api.signIn({ email: 'customer@example.com', password: 'password' });

// Which frequencies may this customer switch a subscription to?
// settings: the customer's portal settings. subscription: the subscription resource to check.
const frequencies = [...getAllowedFrequencies({ settings, subscription })];
```
