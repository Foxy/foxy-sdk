## Type aliases

### AllowedFrequenciesOptions

Input of [`getAllowedFrequencies()`](/docs/reference/admin/functions/getAllowedFrequencies): the store's subscription settings in the camelCase form the Admin API returns, and the subscription to check.

```ts
type AllowedFrequenciesOptions = {
  settings: { subscriptions: { allowFrequencyModification: FrequencyRule[] } };
  subscription: RuleSubject;
};
```

### APIEventMap

Events of the admin [`API`](/docs/reference/admin/classes/API) client by name. The only event is `tokens`. It fires with new [`Tokens`](/docs/reference/admin/types#tokens) after sign-in or a token refresh. Used by [`API.addEventListener()`](/docs/reference/admin/classes/API#addeventlistener) and [`API.removeEventListener()`](/docs/reference/admin/classes/API#removeeventlistener).

```ts
type APIEventMap = {
  /** New tokens were obtained by {@link API.confirmSignIn} or by a token refresh. */
  tokens: CustomEvent<Tokens>;
};
```

### APIInit

Settings for [`new API()`](/docs/reference/admin/classes/API#constructor): the OAuth client ID and secret, the redirect URI for sign-in, and optional overrides for the authorization URL, API base URL, API version, log level and cache.

```ts
type APIInit = {
  clientSecret: string;
  clientId: string;
  /** Redirect URI registered for this OAuth client. Required for {@link API.signIn} and {@link API.confirmSignIn}. */
  redirectUri?: string;
  /** OAuth authorization endpoint. Defaults to {@link API.AUTHORIZATION_URL}. */
  authorizationUrl?: URL;
  level?: number;
  version?: AdminAPIVersion;
  base?: URL;
  cache?: Storage;
};
```

### Constraints

The allowed range for a subscription's next transaction date, merged from every rule that applies: the earliest and latest date, blocked dates, and allowed days of the week or month. Returned by [`getNextTransactionDateConstraints()`](/docs/reference/admin/functions/getNextTransactionDateConstraints).

```ts
type Constraints = {
  min?: string;
  max?: string;
  disallowedDates?: string[];
  allowedDaysOfWeek?: number[];
  allowedDaysOfMonth?: number[];
};
```

### GrantOpts

Input of [`API.getToken()`](/docs/reference/admin/classes/API#gettoken): the OAuth client ID and secret, plus either an authorization code with its redirect URI, or a refresh token.

```ts
type GrantOpts = ({ code: string; redirectUri: string } | { refreshToken: string }) & {
  clientSecret: string;
  clientId: string;
  version?: AdminAPIVersion;
  base?: URL;
};
```

### NextDateRules

The store's rules for changing a subscription's next transaction date. `false` blocks changes, `true` allows any date, and an array lists custom rules. Passed to [`getNextTransactionDateConstraints()`](/docs/reference/admin/functions/getNextTransactionDateConstraints) and inside [`NextTransactionDateOptions`](/docs/reference/admin/types#nexttransactiondateoptions).

```ts
type NextDateRules = boolean | NextDateRule[];
```

### NextTransactionDateOptions

Input of [`isNextTransactionDate()`](/docs/reference/admin/functions/isNextTransactionDate): the date to check, the store's next date rules, and the subscription.

```ts
type NextTransactionDateOptions = {
  value: string;
  settings: { subscriptions: { allowNextDateModification: NextDateRules } };
  subscription: RuleSubject;
};
```

### Resource

A typed API resource as a request returns it: its fields, its `_links`, and the `_embedded` resources the query zooms in on. `TGraph` is a resource type from [`Rels`](/docs/reference/admin/types#rels), like `Rels.Customer`, and `TQuery` is the query you sent. [`Response`](/docs/reference/admin/classes/Response) parses to it, and the subscription helpers take it, for example in [`AllowedFrequenciesOptions`](/docs/reference/customer/types#allowedfrequenciesoptions).

```ts
type Resource<TGraph extends Graph, TQuery extends Query<TGraph> | undefined = undefined> = Links<TGraph> &
  Props<TGraph, TQuery> &
  Embeds<TGraph, TQuery>;
```

### SignInParams

Input of [`API.signIn()`](/docs/reference/admin/classes/API#signin): the `state` value that protects the callback, the OAuth scopes to request, and an optional `prompt`.

```ts
type SignInParams = {
  /** Opaque value to keep in the user's session and pass to {@link API.confirmSignIn}. Protects the callback from login CSRF. */
  state: string;
  /** Space-separated OAuth scopes. Foxy denies a request without any. */
  scope: string;
  prompt?: string;
};
```

### TokenResponse

The raw OAuth token response from Foxy's token endpoint, with snake_case fields. Returned by [`API.getToken()`](/docs/reference/admin/classes/API#gettoken).

```ts
type TokenResponse = {
  refresh_token?: string;
  access_token: string;
  expires_in: number;
  token_type: string;
  scope: string;
};
```

### Tokens

The OAuth tokens an admin [`API`](/docs/reference/admin/classes/API) client holds: the access token, refresh token, expiry time and scope. It is plain JSON, so you can save it and restore it later with [`API.setTokens()`](/docs/reference/admin/classes/API#settokens). [`API.confirmSignIn()`](/docs/reference/admin/classes/API#confirmsignin) returns it, and the `tokens` event in [`APIEventMap`](/docs/reference/admin/types#apieventmap) sends new ones.

```ts
type Tokens = {
  accessToken?: string;
  refreshToken?: string;
  /** When the access token expires, in milliseconds since the Unix epoch. */
  expiresAt?: number;
  scope?: string;
};
```
