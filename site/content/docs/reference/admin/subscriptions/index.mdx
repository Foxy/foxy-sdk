Subscription rules for the Admin API: which frequencies a subscription can switch to, and which next transaction dates are allowed. They read the store's settings in the camelCase form the Admin API returns.

```ts
import { getAllowedFrequencies } from '@foxy.io/sdk/admin/subscriptions';
```
