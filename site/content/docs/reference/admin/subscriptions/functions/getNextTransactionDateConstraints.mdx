```ts
function getNextTransactionDateConstraints(data, rules): boolean | Constraints;
```

Finds which next transaction date modification rules are applicable to
the given subscription and merges them together.

## Example

```ts
import type { NextDateRules } from '@foxy.io/sdk/admin/subscriptions';
import { getNextTransactionDateConstraints } from '@foxy.io/sdk/admin/subscriptions';

// Rules come from the store settings. A rule applies when its `jsonataQuery` matches.
const rules: NextDateRules = [
  { jsonataQuery: 'true', min: '1w', max: '3m', allowedDays: { type: 'day', days: [1, 3] } },
];

const constraints = getNextTransactionDateConstraints({ frequency: '1m' }, rules);
console.log(constraints); // { min: '1w', max: '3m', allowedDaysOfWeek: [1, 3] }
```

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `data` | `unknown` | Subscription to generate constraints for. |
| `rules` | [`NextDateRules`](/docs/reference/admin/subscriptions/types#nextdaterules) | Next date modification config from the customer portal settings. |

## Returns

`boolean` \| [`Constraints`](/docs/reference/admin/subscriptions/types#constraints)

Returns true if all modifications are allowed, false if next date can't
be changed by the customer, object with constraints in any other case.
