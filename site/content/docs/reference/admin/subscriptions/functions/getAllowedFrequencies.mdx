```ts
function getAllowedFrequencies(opts): Generator<string, void, void>;
```

Returns allowed frequencies for given subscription and customer portal settings.

## Example

```ts
import { getAllowedFrequencies } from '@foxy.io/sdk/admin/subscriptions';

const settings = {
  subscriptions: {
    allowFrequencyModification: [{ jsonataQuery: 'true', values: ['1m', '3m', '1y'] }],
  },
};

// `subscription` is the subscription resource from the Admin API.
const subscription = { frequency: '1m' };

const frequencies = [...getAllowedFrequencies({ settings, subscription })];
console.log(frequencies); // ['1m', '3m', '1y']
```

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `opts` | [`AllowedFrequenciesOptions`](/docs/reference/admin/subscriptions/types#allowedfrequenciesoptions) | Subscription and settings. |

## Returns

[`Generator`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Generator)\<`string`, `void`, `void`\>
