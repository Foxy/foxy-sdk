JS SDK for building admin integrations with [Foxy Hypermedia API](https://api.foxy.io/docs). Hypermedia API is designed to give you complete control over all aspects of your Foxy accounts, whether working with a single store or automating the provisioning of thousands. Anything you can do within the Foxy administration, you can also do through the API. This means that you can embed Foxy into any application (CMS, LMS, CRM, etc.) and expose as much or as little of Foxy's functionality as desired.

## Example

```ts
import { API } from '@foxy.io/sdk/admin';

const api = new API({
  clientId: 'client_123',
  clientSecret: process.env.FOXY_CLIENT_SECRET!,
});

// Restore tokens you saved earlier. The API refreshes them when needed.
api.setTokens({ refreshToken: process.env.FOXY_REFRESH_TOKEN! });

const response = await api.follow('fx:store').get();
const store = await response.json();
console.log(store.store_name);
```

### BASE\_URL <MemberMeta type="URL" href="https://developer.mozilla.org/en-US/docs/Web/API/URL" static readonly /> [#base_url]

The default base URL of the Foxy Hypermedia API, `https://api.foxy.io/`. The API uses it when you do not set `base`.

***

### REFRESH\_THRESHOLD <MemberMeta type="number" static readonly /> [#refresh_threshold]

The time in milliseconds before an access token expires when the API starts to refresh it. The value is 5 minutes. A request sent inside this window refreshes the token first, if a refresh token is available.

The default API version, `"1"`. The API sends it in the `FOXY-API-VERSION` header when you do not set `version`.

### confirmSignIn()

```ts
confirmSignIn(callbackUrl, expectedState): Promise<Tokens>;
```

Completes the sign-in started by [API.signIn](#signin): checks the state,
exchanges the code for tokens, keeps them and dispatches `tokens`.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `callbackUrl` | `string` \| [`URL`](https://developer.mozilla.org/en-US/docs/Web/API/URL) | URL Foxy redirected the user to. |
| `expectedState` | `string` | The `state` passed to [API.signIn](#signin) for this user. |

#### Returns

[`Promise`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise)\<[`Tokens`](/docs/reference/admin/types#tokens)\>

New tokens.

#### Throws

AuthError with code `UNAUTHORIZED` when the state doesn't match, the user denied access, or the exchange failed.
