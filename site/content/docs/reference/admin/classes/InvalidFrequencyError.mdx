---
title: "InvalidFrequencyError"
description: "@foxy.io/sdk/admin"
---

Instances of this error are thrown by `getTimeFromFrequency` when
provided with unsupported frequency.

## Example

```ts
import { getTimeFromFrequency, InvalidFrequencyError } from '@foxy.io/sdk/admin';

try {
  getTimeFromFrequency('every week');
} catch (error) {
  if (error instanceof InvalidFrequencyError) {
    console.error(error.message); // Invalid frequency "every week".
  } else {
    throw error;
  }
}
```
