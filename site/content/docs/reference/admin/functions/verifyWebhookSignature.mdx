```ts
function verifyWebhookSignature(webhook): Promise<boolean>;
```

Verifies that the webhook your app has received was indeed sent from our servers.
See [our wiki](https://wiki.foxycart.com/v/2.0/webhooks#validating_the_payload) for more info.

## Example

```ts
import { verifyWebhookSignature } from '@foxy.io/sdk/admin';

// Call this in your webhook handler with the raw request body.
export async function handleWebhook(request: Request): Promise<Response> {
  const isValid = await verifyWebhookSignature({
    signature: request.headers.get('Foxy-Webhook-Signature') ?? '',
    payload: await request.text(),
    key: process.env.FOXY_WEBHOOK_KEY!,
  });

  return new Response(isValid ? 'ok' : 'invalid signature', { status: isValid ? 200 : 401 });
}
```

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `webhook` | `Webhook` | info received with the webhook that needs validation. `webhook.key` is a store secret — only ever call this in a trusted, authenticated context (e.g. a store admin's own dashboard session or your own webhook receiver) — never in code served to or executed by end customers. |

## Returns

`Promise`\<`boolean`\>

True if this webhook has a valid signature.
