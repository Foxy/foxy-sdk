```ts
function createSSOURL(options): Promise<string>;
```

Generates an SSO url for the given configuration.

## Example

```ts
import { createSSOURL } from '@foxy.io/sdk/admin';

// Send a signed-in customer to checkout without asking them to log in again.
const url = await createSSOURL({
  domain: 'https://example.foxycart.com',
  secret: process.env.FOXY_STORE_SECRET!,
  customer: 12345,
});

console.log(url);
```

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `options` | [`SSOURLOptions`](/docs/reference/admin/types#ssourloptions) | sso url configuration. `options.secret` is the store's API key — only ever call this in a trusted, authenticated context (e.g. a store admin's own dashboard session) — never in code served to or executed by end customers. |

## Returns

`Promise`\<`string`\>

SSO URL as string.
