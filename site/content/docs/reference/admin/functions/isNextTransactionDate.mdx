```ts
function isNextTransactionDate(opts): boolean;
```

Checks if given date (YYYY-MM-DD) can be used as the next transaction
date for given subscription.

## Example

```ts
import { isNextTransactionDate } from '@foxy.io/sdk/admin';

const settings = {
  subscriptions: {
    allowNextDateModification: [{ jsonataQuery: 'true', min: '1w', max: '3m' }],
  },
};

// `value` is a date in the YYYY-MM-DD format.
const isAllowed = isNextTransactionDate({ value: '2030-01-15', settings, subscription: {} });
console.log(isAllowed);
```

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `opts` | [`NextTransactionDateOptions`](/docs/reference/admin/types#nexttransactiondateoptions) | Subscription, customer portal settings and value. |

## Returns

`boolean`

True if given date can be used as next transaction date.
