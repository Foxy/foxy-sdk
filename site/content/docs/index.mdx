`@foxy.io/sdk` is the TypeScript SDK for Foxy. It gives you typed clients for the Foxy Admin API, the Customer API and the checkout, plus the core building blocks they share. Install it with `npm i @foxy.io/sdk@2`.

## Sections

- [**Admin API**](/docs/admin): `@foxy.io/sdk/admin`. Manage a store from your server.
- [**Customer API**](/docs/customer): `@foxy.io/sdk/customer`. Build customer portals.
- [**Checkout API**](/docs/checkout): `@foxy.io/sdk/checkout`. Run the cart and checkout in the browser.
- [**Core**](/docs/core): `@foxy.io/sdk/core`. Shared types and helpers.
