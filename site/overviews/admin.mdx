Typed client for the [Foxy Hypermedia API](https://api.foxy.io/docs). Use it on your server to read and change anything in a store. It signs in with OAuth, keeps the tokens, and refreshes them for you.

```sh
npm i @foxy.io/sdk@2
```

```ts
import { API } from '@foxy.io/sdk/admin';
```

## Example

Sign in with the OAuth authorization code flow.

```ts
const api = new API({
  clientId: 'client_123',
  clientSecret: 'secret_123',
  redirectUri: 'https://example.com/callback',
});

// Step 1: send the user to this URL. Keep `state` in their session.
const url = api.signIn({ state: 'random-value', scope: 'store_full_access' });

// Step 2: on the redirect back to your site, check the state and get tokens.
const tokens = await api.confirmSignIn(callbackUrl, savedState);

// Save new tokens whenever they change, and pass saved tokens back later.
api.addEventListener('tokens', event => save(event.detail));
api.setTokens(tokens);
```
